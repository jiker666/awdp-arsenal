# AWDP 一把梭秘籍（Arsenal）

> 面向 AWDP（Attack & Defense Plus）线下赛的一把梭工具箱 + 秘籍。
> 核心理念：**低时间成本、高确定性**。四小时比赛，每分钟都要花在刀刃上。
> 收集自各队公开 writeup / 博客 / 开源仓库，加上本仓库维护者自训靶场实测的结论。
> 每条都标了出处（见 [REFERENCES.md](REFERENCES.md)），未实测的明确标注 ⚠️。

## 这是什么赛制（30 秒版）

- **攻击（Break）和防御（Fix）是两套独立服务**：攻击打的是自己队的实例（类 Jeopardy），**没有队间互打**。
- 防御侧唯一碰你盒子的"攻击者"是**组委会 checker 的固定 exploit**。
- checker 通过 = 分落袋，checker 挂了 = 丢分。防御本质是"让 checker 的 payload 拿不到 flag / 打不通链子"。
- 常见提交格式：`patch.sh` 或 `update.tar.gz`（= `update.sh` + 修复文件），平台在容器里以 root 执行一次。

## 总决策表（拿到防御包先看这个）

| 情况 | 动作 | 成本 |
|---|---|---|
| 规则写了"最小改动/禁通防/文件长度一致" | **真修复**，手改漏洞点 | 高但必须 |
| 规则空白 + checker 判据≈"读到 flag" | **动 flag**（chmod 000 优于 rm） | 1 分钟 |
| 规则空白 + 判据带执行证据 | **通防**（对着判据调黑名单） | 10 分钟 |
| 什么都看不出来 | 先交一发 chmod 000 探判据，输了再真修复 | 5 分钟 |

⚠️ 所有"歪招"（动 flag / alarm 时间差 / NOP free）都是**规则空白处的偷分项**。官方大赛（如 CISCN 决赛有 hexdiff ≤N 字节检查）用会被判违规。开赛第一件事：**读规则**。

## 三条铁律（都是别人吃过亏的）

1. **交任何防御包前，手动过一遍功能**。通防误杀 SLA = 直接判负，比不防还惨。
2. **修补脚本必须能恢复服务**：`|| true` 兜底、别把服务搞挂；很多平台"补丁搞崩服务"会被单独识别。
3. **patch 脚本要幂等**（重复执行不炸）：checker 可能多回合重跑。所有 `|| true` + 存在性检查都是为这个。
